1 · Cómo leer este glosario

El proyecto tiene tres programas que trabajan juntos:

Agente SisgenPrograma en C# que se instala como servicio de Windows en el servidor de cada cliente. Lee las tablas de Sisgen, envía la información al portal y, desde la 1.7.0, maneja los folios. Carpeta agente\.
Servidor del portalPrograma en JavaScript (Node.js) que corre en el servidor de Sisgen. Recibe lo que mandan los agentes, consulta al SII, hace la cuadratura y guarda todo en la base de datos. Carpeta server\.
Pantallas del portalLo que ven los usuarios en el navegador (React). Carpeta client\.

Cada función aparece en una fila con su nombre y, debajo, el archivo:línea donde está. A la derecha, qué hace y cuándo se usa. Las funciones muy pequeñas que solo dan formato (por ejemplo, poner puntos de miles) se agrupan en una sola fila.

Función = un bloque de código con nombre que hace una tarea. Se “llama” escribiendo su nombre, por ejemplo Revisar(). Clase = un grupo de funciones y datos que trabajan juntos, como un departamento: la clase MotorFolios agrupa todo lo que hace el encargado de folios.

Las pruebas automáticas (server\test\) no se incluyen: son programas que revisan que las funciones respondan lo esperado y se ejecutan con npm test.

2 · Palabras y conceptos que se repiten

if / else — “si pasa esto… si no…”.
foreach / for — repetir lo mismo para cada elemento de una lista.
return — termina la función y entrega la respuesta.
continue — salta al siguiente elemento de la lista.
try / catch — intenta algo; si falla, lo atrapa y sigue sin caerse.
throw / Exception — detener la tarea con un mensaje de error.
null — “nada”, sin valor.
lock / candado — “uno a la vez”: dos tareas no tocan lo mismo al mismo tiempo.
Thread / hilo — una tarea que corre en paralelo con otras.
Timer / temporizador — ejecuta algo cada cierto tiempo.
FileSystemWatcher — vigilante que avisa apenas cambia un archivo.
Log — registro del agente: un archivo con lo que pasó y cuándo.
async / await — esperar una respuesta (del SII, de la red) sin congelar el programa.
export — la función se puede usar desde otros archivos.
DBF / CDX — tablas de Visual FoxPro (Sisgen) y su índice.
Registro / campo — fila / columna de una tabla.
XML — archivo de texto con etiquetas; así son los DTE y los CAF.
CAF — archivo del SII que autoriza un rango de folios.
Certificado (.pfx) — firma digital de la persona autorizada ante el SII.
Semilla y token — el SII entrega una semilla, se firma con el certificado y se cambia por un token (pase temporal).
API / ruta — dirección a la que un programa le pide algo a otro (por ejemplo /api/agente/hola).
JSON — formato de texto para enviar datos entre programas.
gzip / base64 — comprimir un archivo y convertirlo a texto para enviarlo.
RCV — Registro de Compras y Ventas del SII.
Traza — seguimiento de envío al SII que guarda DTESERVICE (trazadte / trazabol).
Periodo — un mes, escrito 2026-11.
Llave del agente — clave que empieza con sga_ y autoriza a un agente ante el portal.
Hash — huella de un texto: sirve para comparar sin guardar el original.

3 · Mapa del proyecto

Cómo viaja la información, de punta a punta.

1. En la sucursalSisgen emite documentos y deja ventas en sus tablas DBF, XML en procesos\DTE y seguimiento en trazadte / trazabol.
2. El agente leeCada 30 segundos lee lo nuevo (solo lectura, salvo folios) y lo envía al portal con su llave.
3. El portal guardaRecibe y guarda en su base de datos los documentos de Sisgen.
4. El portal consulta al SIICada hora (y completo cada noche) pide al SII el Registro de Ventas y el estado de las boletas. Si el cliente tiene agente, la consulta la hace el agente con el certificado del cliente, que nunca sale de su servidor.
5. CuadraturaCruza Sisgen contra SII documento por documento y genera alertas: falta en el SII, rechazado, en blanco, folio de otra sucursal, CAF vencido…
6. PantallasEl usuario ve resumen, documentos, alertas, compras y puede bajar XML y PDF.
Folios (aparte)El agente revisa los folios, avisa en las cajas, pide CAF al SII, los carga en Sisgen y salta de rango solo.
